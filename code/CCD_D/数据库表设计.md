# 数据库表设计

## 表 1：image_data 图片数据记录表

### 建表语句

```sql
CREATE TABLE image_data (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY COMMENT '自增主键',
    capture_log_id BIGINT UNSIGNED NOT NULL COMMENT '关联capture_log表主键ID',
    image_name VARCHAR(255) NOT NULL COMMENT '图片文件名, 如20260724_143050_123.png',
    image_path VARCHAR(512) NOT NULL COMMENT '图片完整保存路径',
    image_data MEDIUMBLOB NOT NULL COMMENT '图片二进制内容(PNG 格式)',
    image_size BIGINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '图片文件大小(字节)',
    capture_mode TINYINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '拍照模式:0=单张同步(Single),1=异步回调(Async)',
    capture_time DATETIME NOT NULL COMMENT '图片保存时间',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '记录创建时间',
    INDEX idx_capture_time (capture_time),
    INDEX idx_capture_mode (capture_mode),
    INDEX idx_image_name (image_name),
    INDEX idx_capture_log_id (capture_log_id),
    FOREIGN KEY (capture_log_id) REFERENCES capture_log(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='图片数据记录表';
```

### 字段详情表

| 字段名           | 类型             | 说明                                       |
| ---------------- | ---------------- | ------------------------------------------ |
| `id`             | BIGINT UNSIGNED  | 自增主键                                   |
| `capture_log_id` | BIGINT UNSIGNED  | 关联 `capture_log` 主键 id，建立主外键关系 |
| `image_name`     | VARCHAR(255)     | 图片文件名，由时间戳生成                   |
| `image_path`     | VARCHAR(512)     | 图片完整保存路径                           |
| `image_data`     | MEDIUMBLOB       | 图片二进制内容 (PNG 格式)，最大 16MB       |
| `image_size`     | BIGINT UNSIGNED  | 文件字节大小                               |
| `capture_mode`   | TINYINT UNSIGNED | 0 = 单张同步 Single，1 = 异步回调 Async    |
| `capture_time`   | DATETIME         | 拍照 / 图片保存时间                        |
| `created_at`     | DATETIME         | 记录创建时间，MySQL 自动填充               |

## 表 2：capture_log 拍照操作日志表

> 规则：**仅拍照成功时插入记录，失败直接丢弃，不再记录**，移除 `is_success` 字段。

### 表关联说明

1. `capture_log`：每次成功拍照生成一条日志；
2. `image_data`：一条图像记录绑定一条拍照日志，通过 `capture_log_id` 外键关联 `capture_log.id`；
3. 外键策略：`ON DELETE CASCADE`，日志删除时级联删除对应图像记录（可根据业务改为 `ON DELETE RESTRICT`）。

### 建表语句

```sql
CREATE TABLE capture_log (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY COMMENT '自增主键',
    capture_time DATETIME NOT NULL COMMENT '拍照时间',
    capture_mode TINYINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '拍照模式:0=单张同步(Single),1=异步回调(Async)',
    capture_index INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '该模式下累计第几次拍照(从1开始递增,永不重置)',
    image_path VARCHAR(512) NOT NULL COMMENT '本次拍照保存的完整路径',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '记录创建时间',
    INDEX idx_capture_time (capture_time),
    INDEX idx_capture_mode (capture_mode)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='拍照操作日志表';
```

### 字段详情表

| 字段名          | 类型             | 说明                                    |
| --------------- | ---------------- | --------------------------------------- |
| `id`            | BIGINT UNSIGNED  | 自增主键（被 image_data 外键关联）      |
| `capture_time`  | DATETIME         | 拍照时间                                |
| `capture_mode`  | TINYINT UNSIGNED | 0 = 单张同步 Single，1 = 异步回调 Async |
| `capture_index` | INT UNSIGNED     | 当前模式下拍照累计序号，从 1 递增不重置 |
| `image_path`    | VARCHAR(512)     | 图片完整存储路径                        |
| `created_at`    | DATETIME         | 日志记录创建时间，MySQL 自动填充        |
